# Распознавание вина по фото

Сервис по контракту организатора (`Датасет/eval.zip` → `README.md`): фото бутылки →
Top-1 `slug` из каталога. Каталог — CSV-выгрузка Strapi `Датасет/strapi_output0709.csv`
(2103 слага), картинки — дамп `uploads` из `prod-svoe-vino-strapi.part1..3.rar`.

## Запуск

Продакшен (Dokploy, Docker) — `docs/DEPLOY.md`. Локально:

```
npm run ml:setup                    # .venv-ml: torch 2.14 + CUDA 12.6, timm, open_clip (≈3 ГБ)
npm run ocr:paddle:setup            # .venv-ocr: PaddleOCR (см. DATABASE.md)
"C:\Program Files\7-Zip\7z.exe" x Датасет\prod-svoe-vino-strapi.part1.rar -odata\raw\strapi
npm run dataset:manifest            # slug → файл-оригинал, нужен доступ к базе (см. ниже)
npm run serve:recognizer            # http://127.0.0.1:8080: /v1/eval/predict, /v1/recognize, /health
```

Проверка организатора, из распакованного `eval.zip` (нужны bash, curl, jq — Git Bash):

```
./participant_test.sh --images-dir ./queries --manifest ./queries.tsv \
  --endpoint 'http://127.0.0.1:8080/v1/eval/predict' --output ./predictions.jsonl
```

Ответ сервиса: `{"slug", "confidence", "candidates", "ocr_text", "box", "ms"}`. Скрипт
организатора читает только `slug`. `--min-confidence 0.5` включает отказ: при уверенности
ниже порога `slug: null`. По умолчанию порог 0 — сервис всегда отвечает (см. «Вино вне каталога»).

## Данные

`scripts/build-dataset-manifest.mjs` → `data/raw/dataset/catalog.jsonl` + `manifest-report.json`.

- В CSV 4147 строк, но уникальных слагов 2103: остальное — точные дубли строк.
- Файл ищется сначала по `wines.image_url` из зеркала в базе (2037 слагов — точное имя),
  потом по имени фото из CSV. Strapi при загрузке переименовывает файл:
  `@sindresorhus/slugify(имя, {separator: '_', lowercase: false}) + '_' + 10 hex`
  (кириллица транслитерируется, camelCase рвётся: `Агора_Блэк Стоун` → `Agora_Blek_Stoun_e98339ae1b`).
  Та же библиотека той же версии (1.1.0) воспроизводит имя точно: на 2037 слагах с эталоном
  из базы совпало 2031, в 6 остальных имя из CSV не находит файла вовсе (медиа перезаливали).
- Сматчены все 2103: 2037 по базе, 56 по имени, 10 — несколько загрузок с тем же именем,
  взята самая свежая по mtime.
- **7 фото делят по два слага** (14 слагов): `aligote-barrel-2024/2025`, `kokur-2025` и
  `kokur-suhoe-2025`, `pino-nuar-2025` и `method-classic-kokur` (у второго чужое фото) и др.
  Визуально они неразличимы; развести может только текст (год, название).
- 1942 из 2096 уникальных рендеров — вырезанные бутылки с прозрачным фоном.

База нужна только сборке манифеста. Сервис от неё не зависит: индекс OCR-матчера строится
из манифеста (`scripts/lib/catalog-manifest.mjs`).

### Реальный тестовый набор

`data/raw/dataset/real/queries.jsonl`, 14 кадров:

- 3 контрольных фото организатора. В каталоге из них **только одно** — Массандра
  «Мускатель белый». «Табия Пино Нуар 2025» (этикетка с шишкой) и «Aristov Donum XXIV»
  нет ни в CSV, ни в дампе uploads, ни в живом API сайта на 21.09.2026.
- 11 фото из дампа uploads (пресса, соцсети виноделен), найденных `ml/mine_real.py`
  и подтверждённых глазами. 10 из них в каталоге, 1 — «Коммуналка Aligote Sur Lie»,
  которого нет, а в каталоге есть «Aligote Barrel» того же дизайна (трудный негатив).

**Смещение:** 10 из 11 кадров из дампа отобраны самой SigLIP2 (попали в её топ-3), поэтому
они легче среднего. Непредвзятый кадр в каталоге — один (Массандра).

## Конвейер

```
фото ─► visual worker (.venv-ml, GPU)                  ─► сходство с 2096 референсами
        локатор бутылки (Faster R-CNN COCO, класс bottle)
        4 вида запроса × 2 вида референса, max по парам
        энкодер SigLIP2 ViT-B/16, дообученный
    └─► рамка бутылки ─► OCR worker (.venv-ocr, CPU)     ─► текст
                          PaddleOCR PP-OCRv5 по кропу
                                     └─► matcher.mjs по каталогу ─► скоры текста
кандидаты = визуальный топ-20 ∪ текстовый топ-5 ─► fusion.mjs (условный логит) ─► slug, p
```

Оркестрация — Node (`scripts/lib/recognizer.mjs`), модели — постоянные Python-воркеры с
протоколом «JSON по строке» (`ml/worker.py`, `ocr/paddle_worker.py`). Один и тот же код
отвечает в сервисе и в офлайн-оценке `scripts/eval-recognizer.mjs`.

## Модель

**Выбор энкодера** (`ml/bench_zeroshot.py`, 1000 синтетических кадров, кроп по известной рамке):

| Энкодер (без дообучения) | top-1 | top-5 | Массандра, ранг эталона |
|---|---|---|---|
| DINOv2 ViT-S/14 | 50.7% | 76.6% | 1007 |
| DINOv2 ViT-B/14 | 31.6% | 53.5% | 1427 |
| CLIP ViT-B/16 (LAION-2B) | 39.4% | 64.1% | 16 |
| **SigLIP2 ViT-B/16 @256** | **64.9%** | **91.9%** | **4** |

SigLIP2 фактически читает этикетку: по фото Массандры весь её топ — вина Массандры.

**Виды.** Один эмбеддинг плохо переживает разницу масштабов (крупный план этикетки против
рендера всей бутылки). Запрос: рамка бутылки, её нижняя часть (этикетка), центр кадра, кадр
целиком. Референс: бутылка и нижние 62% (этикетка). Сходство = максимум по 8 парам.

**Синтетика** (`ml/synth.py`): вырезанная бутылка на фоне из не-каталожных фото uploads,
соседи по бокам, цилиндрическое затенение и блик, перспектива, ценник, планка полки, баланс
белого, шум, смаз, JPEG. 40% кадров — крупный план этикетки с обрезанными горлышком и дном.
Фоны делятся по хэшу имени: eval-фоны на обучении не встречаются; реальные тест-кадры из
фонов исключены.

**Дообучение** (`ml/train.py`): последние 4 блока + attention-pool (35.4 млн параметров),
CosFace по 2096 классам, прототипы стартуют с zero-shot эмбеддингов. 10 эпох × 4192
сэмпла, ~5 мин на эпоху на GTX 1050 Ti. Лучший чекпойнт — 4-я эпоха
(`data/raw/model/checkpoints/ft1-best.pt`), дальше модель доучивает синтетику без прироста
на отложенных кадрах.

**Локатор** (`ml/locate.py`): Faster R-CNN MobileNetV3 (COCO, класс bottle), выбор самой
центральной рамки; рамки, чей центр дальше 20% ширины от середины, отбрасываются — это
соседи. Детектор находит цель лишь в 64% синтетических кадров; без отсева в 12.8% кадров
выбирался сосед. Отсев: top-1 83.3% → 88.2% при потолке 90.0% с идеальной рамкой.

## Результаты (21.09.2026)

Синтетика — кадры 300:1000 фиксированного eval-набора (0:300 — отбор чекпойнта), полный
путь сервиса: локатор, виды, OCR, матчер, слияние.

| Конфигурация | синтетика top-1 | top-5 | реальные в каталоге (11) |
|---|---|---|---|
| SigLIP2 zero-shot | 71.9% | 90.3% | 9/11 |
| **SigLIP2 дообученный (ft1-e4)** | **87.0%** | **99.0%** | **9/11** |

Слияние, обученное на 300:700, на отложенных 700:1000: 85.0% против 84.3% у весов по
умолчанию — в пределах шума. Текст на синтетике почти бесполезен: рендеры мелкие (медиана
336 px в ширину), OCR не читает на них различающее слово. На реальных фото 3024×4032 текст
читается хорошо («MACCAHAPA … МУСКАТЕЛЬ БЕЛЫЙ», «SIKORY ПИНО НУАР СЕМИГОРЬЕ») и разбивает
визуальные ничьи: Belmas «Pn» и «Vi» дают одинаковое визуальное сходство, выбирает текст.
Уверенность откалибрована: ECE 0.05 на синтетике (у zero-shot 0.24).

Прогон `participant_test.sh` организатора против сервиса: EXIT 0, без `null`, 2.7–4.6 с на
кадр (визуал ~0.9 с, OCR ~1.7–2.7 с на полноразмерном фото). Массандра — верно; Табия и
Donum — чужой слаг (их нет в каталоге).

### Что ограничивает точность

Разбор 91 ошибки дообученной модели на 700 синтетических кадрах:

| Причина | Ошибок | Доля кадров |
|---|---|---|
| **Разные вина с одинаковым фото в каталоге** | 19 | 2.7% |
| Та же винодельня, другое вино серии (одинаковый дизайн этикетки) | 49 | 7.0% |
| Прочее: сосед по полке, трудная сцена | 22 | 3.1% |
| Очень похожие рендеры | 1 | 0.1% |

**В каталоге 49 пар разных вин с практически одинаковым рендером** (сходство > 0.95, 95
рендеров, ~4.5% каталога), многие — пиксель в пиксель: Абрау «Баянширей» (белое) и «Мадраса»
(красное), Agora Yachting Cabernet и Sauvignon, «Шато Ле Гран Восток Красностоп» и «Шато
Ай-Даниль Гренаш» (разные винодельни). Это ошибки данных: визуально такие вина неразличимы в
принципе, развести их может только текст. Отдельно — дубли одного вина под двумя слагами с
разными рендерами (`abrau-dyurso-brut-dor-blanc-de-blancs-…-12` и `…-125`): какой слаг
считает правильным организатор, неизвестно. На реальном наборе это одна из двух ошибок.

### Вино вне каталога

2 из 3 контрольных фото организатора — вина, которых нет в каталоге. Softmax-уверенность
относительна и на чужом вине бывает высокой (Donum 0.58), а абсолютное визуальное сходство
лучшего референса — нет: Табия 0.312, Donum 0.305 против минимум 0.576 у правильных ответов на
реальных фото. Порог `--min-visual 0.4` на 700 синтетических кадрах не отказывает ни разу, на
11 реальных в каталоге — тоже, а обе чужие бутылки превращает в `slug: null`. «Коммуналка
Aligote Sur Lie» (0.804) так не ловится: дизайн тот же, что у «Aligote Barrel» из каталога.

Включать ли отказ по умолчанию, зависит от правил организатора: засчитывается ли `null` на
вине вне каталога. Пока порог выключен — сервис всегда отвечает, как требует README.

## Ограничения окружения

- GTX 1050 Ti (Pascal, 4 ГБ): fp16 в 64 раза медленнее fp32, autocast включается только на
  Volta+. torch 2.14 cu126 поддерживает sm_61; сборки cu128+ — уже нет.
- Узкое место обучения — генерация сцен на CPU (i5-4440, 4 ядра): 187 мс на сэмпл после
  оптимизаций (кадр 480×640, LUT вместо float-арифметики, кеш уменьшенных копий).
- Кеш `data/raw/cache/<размер>/` — уменьшенные PNG; первый прогон по всем оригиналам ~7 мин.
- База доступна не всегда (21.09 днём — connect timeout): сервис от неё не зависит.
